# CIE 2 – Activity 2: Classification

## Objective
To build a binary Logistic Regression model, generate probabilities and predictions, and study sigmoid output, decision threshold, and model evaluation metrics.

## Dataset
**Dataset Name:** Breast Cancer Wisconsin Dataset  
**Source:** Scikit-learn  
**Total Records:** 569  
**Total Features:** 30

**Dataset Link:**  
https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_breast_cancer.html

## Target Classes
- 0 – Benign
- 1 – Malignant

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Activities Performed
- Loaded and explored the Breast Cancer dataset.
- Checked dataset information, missing values, duplicates, and statistical summary.
- Visualized class distribution.
- Split the dataset into training and testing sets.
- Applied feature scaling using StandardScaler.
- Implemented Logistic Regression using a pipeline.
- Studied the sigmoid function.
- Calculated model coefficients and intercept.
- Generated prediction probabilities and class predictions.
- Created and visualized the confusion matrix.
- Evaluated the model using Accuracy, Precision, Recall, Specificity, F1-Score, and ROC-AUC.
- Generated a classification report.
- Compared Logistic Regression with a baseline model.
- Studied the effect of different decision thresholds.
- Plotted the ROC curve.
- Predicted the class of a new example.

## Conclusion
A Logistic Regression classification model was implemented successfully. The model was evaluated using classification metrics, a confusion matrix, and an ROC curve.
